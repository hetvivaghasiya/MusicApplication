# Music Listening Mobile Application 🎵

## About Project
The Music Listening Application is a mobile application that provides two separate panels: Admin Panel and User Panel. Admins can manage music and users, while users can browse, search, and listen to their favorite songs through the mobile application.

## Application Modules

### 1. Admin Panel
- Admin login.
- Manage users.
- Add, update, and delete songs.
- Manage music categories.
- Manage the music library.

### 2. User Panel
- User registration and login.
- Browse available songs.
- Search for songs.
- Listen to music.
- Play and pause songs.
- Explore music categories.

## Features
- Separate Admin and User panels.
- Music library management.
- User management.
- Online music listening.
- Song search functionality.
- User-friendly mobile interface.

## Project Objective
The main objective of this project is to develop a mobile application that allows administrators to manage music content and users to easily discover and listen to their favorite songs.
